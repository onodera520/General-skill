# Smart Storyboard Generator

`generator` 是一个面向 Codex 的分镜设计工具。它把剧本和角色、场景、道具图片，整理成可以直接交给中国 AI 图像和视频工具使用的中文分镜与提示词。

## 它能做什么

- 把剧本拆成故事节奏、视频片段和具体镜头。
- 为每个镜头设计景别、机位、构图、人物站位、动作、光线、道具和镜头运动。
- 为每个镜头生成一份中文 Image Prompt，用于生成静态画面。
- 为每个视频片段生成一份中文智能镜头 Prompt，用于描述镜头顺序、动作变化、运镜和声音。
- 根据角色三视图、场景图和道具图保持画面中的人物与空间一致。

它只负责设计分镜和提示词，不负责生成或检查实际图片、视频。

## 工作方式

```text
剧本和视觉资产
        ↓
梳理故事与声音
        ↓
安排时间和视频片段
        ↓
设计每个镜头
        ↓
输出分镜描述和中文提示词
```

它会先完成镜头设计，再把已经确定的设计转写成提示词，不会在写提示词时临时改变拍法。

## 连贯性保证

- 同一个人物会沿用同一套身份、服装和外观设定。
- 同一个场景会保持门窗、家具、光源和出入口的位置关系。
- 前后镜头会延续人物的站位、朝向、视线、姿势、手里拿的东西和动作进度。
- 道具的拿取、交接、放下和损坏会有明确记录。
- 对话、旁白和音效会按原来的先后顺序衔接，不重复，也不会无故漏掉。
- 如果剧本允许换装、受伤、换场或时间跳跃，会把这些变化作为明确事件记录。
- 看不到的资产信息会标记为未知或假设，不会假装已经从图片中确认。

## 使用方式

在 Codex 中使用 `$generator`，并提供：

1. 剧本、场次或剧情片段。
2. 角色、场景、道具的图片，或文字设定。
3. 可选的对白／旁白／音效时间、画幅、风格、时长和其他要求。

默认会输出一个中文 `storyboard.md` 文件。每个视频片段包含详细镜头描述、按顺序排列的静态画面提示词，以及一份完整的智能镜头提示词。

## 项目结构

```text
generator/
├── SKILL.md       # 使用规则
├── references/    # 剧本、镜头、连续性和提示词规则
├── templates/     # 输入和输出模板
└── evals/         # 场景、对白、动作和连续性评测
```

项目中的规则和评测用于保证镜头设计前后一致；它不等同于对外部生成结果进行验收。
