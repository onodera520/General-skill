# Clip Markdown 输出模板

默认保存为一个UTF-8 storyboard.md，位置、重名处理按SKILL.md交付规则；对话仅提供真实文件链接。按Clip全局顺序排列，每个Clip只有以下三个正文部分，不另附JSON、设计表或验证报告。变量替换为实际内容。

## Clip <N>｜总时长<duration>秒

### 详细镜头描述

<按Shot顺序描述本Clip的剧情、摄影、动作、表情、空间及衔接。清晰角色资产只声明严格继承对应图，省略固定外貌／服装清单。动态状态与相机相对朝向保留。必要假设、短尾段或超长因果例外在这里简短注明。>

### Image Prompts

#### 镜头<M>｜图<M>

```text
<该Shot指定静态关键帧的中文Image Prompt>
```

<按本Clip内Shot顺序重复镜头小标题与Image Prompt代码块；每个Shot一份，图号全片连续。>

### 智能镜头 Prompt

```text
<按智能镜头模板写一份覆盖整个Clip的中文提示词，逐镜列参考图与“镜头M，【时长】Xs。”及详细画面；结尾附快切要求。>
```

详细描述保留完整镜头序列，以“镜头M，【时长】Xs。”分镜列出摄影、动作及承接；不出现“几秒–几秒”起止区间。Image Prompt不因镜头变短而缩成简略标签，仍逐镜完整描述适用细节。Image Prompt只写指定时刻，视频从真实Clip起点到终点；中途代表帧不自动作为首帧。Clip、Shot、图号按全片顺序续编号，内部核对版本映射。提示词各自与明确引用的资产配合使用，不用“同上”省略执行信息。

分批结果按顺序汇入同一文件。未完成时在末尾一句说明当前Clip／镜头范围与下一编号；不将partial标为完成。
