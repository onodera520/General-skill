# 智能镜头 Prompt 模板

替代原Video Prompt的对外标题和正文格式，内部video_prompt字段及Clip／Shot契约保持不变。只读定稿Clip、全部Shot、timeline、连续性与资产；拆镜由 [镜头规划](../references/shot-planning.md) 完成。每个Clip输出一个可复制的中文text代码块。

```text
【题材／风格】{已定稿的必要风格与画幅}
【资产与初始站位】{严格继承清晰绑定的角色／场景资产，按场景首次进入的镜号描述全部在场人物的静态位置与关系；画外在场不强行入画}
【分镜参考图】镜头{M}→图{M}（{起始帧／代表帧／结束帧}，镜内关键帧{单点时间}s）
镜头{M}，【时长】{duration}s。{景别、运镜、摄影方向与高度；具体画面、前中后景、人物朝向、动作、表情、遮挡、道具接触、光线及承接。}
【分镜参考图】镜头{M+1}→图{M+1}（{用途}，镜内关键帧{单点时间}s）
镜头{M+1}，【时长】{duration}s。{该镜独立且详细的摄影与画面描述。}
{有声音时在对应镜头后写首次声音条目，原文仅一次；无声音省略此占位段。}
【全局补充】{仅贯穿整段的必要要求，无额外补充时可省略此行}
参考分镜图，严格按照分镜脚本生成一段快速切镜的视频，每个分镜不需要很大的动作幅度。{按原剧情选择声音说明}不要出现字幕。每个分镜硬切转场。
```

## 逐镜填写

- 镜号与图号全片连续，每个真实Shot对应一份详细Image Prompt和一条镜头段，不能合并多个Shot为一条，也不能在正文临时新增镜号。参考图注释放在对应镜头前；逻辑图号不是已生成文件路径，角色资产标签与分镜图号分开。代表帧／结束帧不自动当视频首帧。
- 单镜优先0.5–2秒；填定稿的真实duration，不能一律复制0.5秒。Clip仍按既有分组，所有镜头时长之和等于Clip.duration。必要例外由设计阶段确定，Builder不得改时长、动作或切镜。
- 详细镜头描述与提示词均不写起止秒数区间，例如“0–1秒”“第1秒至第2秒”。内部Shot、Clip与声音时间线保留精确区间以供对齐。不同拍法或可独立呈现的阶段先在设计层拆Shot；同一短镜的连续动作使用“先、随后、保持、直到”等词表达。不删除原来区间内的事件来满足格式。
- 细节不因镜头短而减少：保留景别、机位高度／方向、运镜、可见人物相机相对朝向、头脸与视线、动作幅度和阶段、环境、道具与手别、光线及重要遮挡。只写适用于本镜的已定稿事实；不能把多步大动作塞入极短时长。Image Prompt仍是该镜一个关键帧的完整描述，不写成多帧拼图。
- 清晰绑定角色声明严格继承对应资产图，形象冲突以资产为准，不重列固定外貌或服装。保留当前动态状态。画面描述用姓名／稳定标签，原台词代词不改。续接同场景首镜保留单人中景／近景／特写或空镜要求，禁止直视镜头。

## 声音与结尾

- 没有台词／旁白且没有指定音乐时，结尾使用用户要求的完整句：
  参考分镜图，严格按照分镜脚本生成一段快速切镜的视频，每个分镜不需要很大的动作幅度。没有台词，没有音乐，不要出现字幕。每个分镜硬切转场。
- 有原台词／旁白时，保留全文及连续音轨，结尾改为“保留上述台词／旁白并跨镜连续播放，没有音乐，不要出现字幕”；不能同时写“没有台词”。原剧情或用户明确指定音乐则保留该音乐并相应改写“没有音乐”，不无故增加音乐。明确要求一镜到底或其他转场时遵循该要求并同步改结尾，不能与定稿Spec矛盾。
- 原台词在开始镜头后首次写“【连续台词】{说话者与语种}，从镜头M开头开始，跨后续镜头连续播放：{原文用花括号包围}”。必要时以“镜头M内第0.3秒开始，镜头N内第0.8秒结束”两个单点定位，不能使用秒数起止区间。后续镜头只注明原音轨延续。跨Clip只写本Clip的原文片段，不重复整句。已有旁白同理，不把动作或心理说明念成旁白。
- 音效在对应镜头后用“【音效】<指定声音与发生动作／镜号>”，跨镜声音在首次条目注明连续覆盖的镜号，不逐镜重启。无指定音效不自动补脚步等声音；需标记时写<未指定>，明确无音效写<无音效>。无音乐不等于无环境音，亦不能消除原台词。
- “不要出现字幕”指不叠加对白字幕或额外说明文字；剧情必要的门牌、标签、便条文字依原文保留，明确为场景内实物文字，不当作台词或字幕。除用户明确要求，不新增文字。
- 全局补充仅收录贯穿Clip的已定稿要求。逐镜光向、焦点、结尾瞬间状态放在相应镜头段；不输出模型专用参数。
