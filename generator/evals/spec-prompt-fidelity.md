## 任务

提供一份定稿镜头设计：SHOT_003，spec_version=2，4 秒中景、平视、固定机位。短黑发深蓝夹克的林川在画面右侧前景，面向左侧的长黑发绿衬衫阿岚。0–1 秒双方静止；1–2 秒林川右手把红钥匙交给阿岚左手；2–4 秒阿岚握住钥匙，林川右手已空。东侧桌上方固定白吊灯照亮两人，米色外套留在桌上。Image Prompt 的关键帧在 0.5 秒，为起始静止阶段的代表帧；必须看见钥匙仍在林川右手。整个镜头禁止添加第三人、重复钥匙或运镜。只转写中文分镜描述、中英 Image Prompt 和中英 Video Prompt，不重新导演。引用源文片段保留追溯，不编造原输入没有的 JSON 路径，不改变事实。

## 验收

- 三类输出引用同一镜头及版本。Image Prompt 是交接前：阿岚尚未持钥匙；Video Prompt 则包括交接全过程。
- 中景、平视、固定机位、两人位置、手别、吊灯和桌上外套不改变。
- 不为“电影感”新增特写、推进、烟雾、暖色逆光或背景人物。
- 若输入 Spec 另有“钥匙在阿岚右手”的相冲突字段，Prompt Builder 返回设计阶段修订，不暗自择一。
- 为本用例另造错误输出（反转左右、复制钥匙、增加推进、使用专属参数），确认评测能识别这些语义变化。
