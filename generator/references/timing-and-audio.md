# 最短可理解时间线与连续声音

在 Beats 和资产绑定后读取本文件。先规划最小可视化补全，再按 [时间线契约](../templates/timeline-schema.json) 定稿时间线，最后才进入 [Clip 分组](clip-planning.md)。时间线与中间字段留在工作记录，不默认导出。

## 最小补全与估时边界

按微动作 → 神态变化 → 道具反馈 → 环境反馈 → 空镜／视觉隐喻的顺序表达原文已有信息。补充用 execution_detail，挂到原 Beat，不伪造 source。明确群体存在（顾客排队、人群围观）时才建立差异化 NPC，使用稳定名字／角色标签；地点或职业本身不授权补路人。NPC 不加台词、支线或无关背景。空镜与隐喻不能引入未发生事件；闪回仅可使用原文明示的回忆内容。

原剧情必须完成的动作和原有声音决定基线。补充占用原有区间，与支持的动作或声音并行，不延长基线、不拖慢台词；放不下时简化或移除低优先级补充。不得把仅有心理描述的无声音段强行增加旁白。若原文只有不可见信息，选择最小可见表达作为该 Beat 的必要载体估时，而非再叠加一段“原心理时长”。

## 最短可理解估时

| 内容 | 优先参考的屏幕时长 |
|---|---|
| 抬眼、转头、伸手等微动作 | 0.3–1秒 |
| 拿钥匙、推门等单一信息动作 | 0.5–1.5秒 |
| 拿外套转身离开等连续动作 | 1–3秒 |
| 愣住、闪躲视线等反应 | 0.3–1秒 |
| 必要的普通／情绪停顿 | 0.3–0.8秒 |
| 有叙事作用的环境留白 | 0.3–2秒 |

区间是快速节奏参考，不是硬上限。根据移动距离、接触过程、道具操作及可理解性延长必要动作，并记录 estimate_basis；不靠瞬移、无依据跳时或不合理加速压缩。没有叙事作用的留白不安排。动作省略必须是允许的显式时间转场，不能删关键交接或状态变化。

中文台词按情绪选择3–6字/秒，标点不计入发音字数；数字、缩写按实际读法估计，不能改写台词原文。其他语言按该语言的可理解语速估计并写依据，不机械套中文字速。有用户提供的实际音轨时使用真实时长与可定位的台词区间。估时是设计值，不声称实测。

“随后、之后”对应顺序相加；明确同时发生的内容在同一时间起点取最长时长。部分重叠用实际区间计算，不能将所有项目相加或全部取最大值。用 blocks 的全局 start/end、depends_on、overlaps_with 记录；不擅自把顺序改并行。total_duration 为覆盖原剧情的时间线终点；无故的区间空洞不允许。

## 原文声音唯一记录

每段原台词／已有旁白只建一次 audio_event：audio_id、kind、speaker、language、text、全局start/end、delivery、source和estimate_basis。source 记录 source_id 与原文字符区间（Unicode码点，0起始，左闭右开）；必须能切出完全一致的 text。旁白使用稳定“旁白”标签；人物用已绑定名称，不虚构说话者。音效 kind=sfx，只承载已指定声音；无原文字面来源时 source=null 并明确设计依据，不能伪装为原文对白。

同一原句跨 Shot 仍是同一 audio_id；跨 Clip 在安全语义位置分配该音轨不同 text_start/text_end 与播放区间，所有片段按顺序拼接恰好恢复原文，不能重播、漏字或改变语言。跨 Clip 无法合理切开的一句可归入不可拆因果／声音段，保留完整性并记录原因。Shot action_design 可保留本镜说话表现，但声音原文以 audio_events 为唯一播放权威；不得把相同台词再次作为新的播放事件。

连续台词超过5秒，Shot Planning 必须安排至少一次语义相关的听者反应或细节切镜，在覆盖该台词的 Shot 区间中记录。声音不断、不重播。画外延续不是新增旁白，也不把剧本动作／心理叙述念出来。实际智能镜头 Prompt 按视频模板用镜头编号及必要的单点偏移定位连续声音，台词原文仅表达一次；后续镜头只注明该声音延续，不重播。内部时间区间照常保留，不将起止秒数区间输出到正文。

## 定稿与关联

blocks 标 original 或 supplement；补充的 overlays_block_id 必须指向原内容且其区间能容纳补充。不可拆的即时因果或不可分声音区间记录为 indivisible_groups，不把一般剧情因果锁成整场一组。原文分镜编号不决定组边界。

timeline_version 定稿后供 Clip Plan 引用，分组不得回改估时。若后续发现真正的可执行性错误，先将受影响设计标 provisional，回到本阶段纠正依据并升版本，再废止旧分组重算；不能为了10–15秒要求触发这种修订。Prompt Builder 没有修订权限。
