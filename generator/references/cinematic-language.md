# 摄影语言：目的转为机位

读取 Shot Plan、场景空间档案及 [Shot Spec 契约](../templates/shot-schema.json)。本阶段负责 shot_size、camera_angle、camera_height、camera_position、camera_direction、focus；将已确定的风格与画幅写入 visual_style、aspect_ratio，供只读转写使用。所有字段均为明确拍摄设计，未指定数值不冒充测量。

## 按任务选景别

| 叙事需要 | 选择依据 |
|---|---|
| 建立地点、人物数量及出入口 | 远景／中远景，相关地标与路线同时可读 |
| 手部交接、两人关系与表情同时重要 | 能容纳脸与关键双手的中景／中近景，裁切不能隐藏关键动作 |
| 微表情或明确物件信息揭示 | 近景／特写，但要有可承接的空间和物件身份依据 |
| 连续身体动作与移动方向 | 中景至全景，预留路径，不把脚步和接触点剪掉 |

景别根据画面实际裁切描述，不只写缩写。例如“中景，人物腰部以上，关键双手完整入画”。固定机位也要填写方向与焦点，不能以“无运镜”替代摄像机位置。

## 空间化机位

camera_position 写相对世界地标的位置；camera_height 写相对地面／主体的高度；camera_direction 写从该位置朝哪个世界目标看；camera_angle 写水平、俯仰、倾斜等视角。正面、侧面、三分之四、越肩是相对主体关系，不是完整世界机位。

例如：摄像机在桌南侧偏西、与站立人物胸部等高，朝桌东侧阿岚的面部看，轻微仰视；林川左肩处于前景。需核对实际几何，不能机械地认定某个方位必定越过某侧肩膀。

焦距可在确有必要时放入摄影描述，并说明画幅／等效基准；默认用视角、景别、透视与主体距离关系避免伪精确。不以“35mm”自动推出人物占比或精确景深。focus 明确焦点目标、景深与是否转移；转焦不等于推镜。

## 镜内变化

顶层摄影字段表示镜头 t=0 的设计；若镜头移动或人物靠近导致景别／焦点变化，在 camera_movement、focus.change 和关键帧 camera_state 中给出实际阶段，不能所有时刻沿用起始景别。

与 [人物调度](blocking-and-staging.md) 协调后核对画面投影，再交给 [构图](composition.md)。拍法不满足关键动作可见性时返回设计调整，不让 Prompt Builder 解决。
